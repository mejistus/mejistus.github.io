在扩散模型里，\(log\Pi_{\theta}\) 指\colorbox{mdc2}{\textcolor{mdc1}{生成整张图片过程的对数概率}}，也就是反向去噪过程中\colorbox{mdc2}{\textcolor{mdc1}{每一步的对数概率的累加和}}。

这个计算主要发生在 \verb|flow_grpo/diffusers_patch/pipeline_with_logprob.py| 文件中。

\section{核心思想}

反向去噪过程可以看作是一个马尔可夫链：

\[
p(x_0) = \int p(x_0|x_1) p(x_1|x_2) \dots p(x_{T-1}|x_T) p(x_T) dx_{1 \dots T}
\]

其中，\(p(x_T)\) 通常是一个标准正态分布，而每一步 \(p(x_{t-1}|x_t, \text{prompt})\) 都被建模成一个高斯分布。

因此总对数概率 \(log P(x_0)\) 就是从 \(t=T\) 到 \(t=1\) 每一步 \(log p(x_{t-1}|x_t)\) 的和。

\[
\log \Pi = \log p(x_0) \approx \sum_{t=1}^{T} \log p(x_{t-1} | x_t, \text{prompt})
\]

\section{具体实现}

在 \verb|pipeline_with_logprob| 函数里，计算过程大致如下：

\begin{enumerate}
  \item 初始化：进入主要的去噪循环之前，先初始化一个 \verb|log_prob| 累加器，通常是一个全零张量，形状与 \verb|batch size| 相同。
  \item 去噪循环 (Denoising Loop): 代码会遍历所有的时间步 \(t\) (从 \(T\) 到 \(1\))。在循环的每一步中：
  
  \begin{itemize}
    \item 模型预测：扩散模型（代码里是 transformer 或 unet）以当前噪声图像 latents (\(x_t\)) 和时间步 \verb|t| 为输入，预测当前步骤要移除的噪声 \verb|noise_pred|。
    \item 计算上一步的分布参数：用 \verb|noise_pred|、当前 latents (\(x_t\)) 和调度器（\verb|scheduler|）的公式，算出上一步 latents\_prev (\(x_{t-1}\)) 的高斯分布均值（mean）和方差（variance）或对数方差（\verb|log_variance|）。
    \item 获取实际的 \verb|latents_prev|：调度器的 step 函数会实际生成上一步的噪声图像 \verb|latents_prev|。
    \item 计算单步 \verb|log_prob|：这时有了 \(p(x_{t-1}|x_t)\) 的高斯分布参数（均值和方差），也知道实际生成的样本点 \verb|latents_prev|，用高斯密度函数（PDF）就能算出 \verb|latents_prev| 在这个分布下的对数概率。
    
    高斯分布的对数概率公式为：
    
    \[
    \log \mathcal{N}(x; \mu, \sigma^2) = -\frac{1}{2} \log(2\pi\sigma^2) - \frac{(x - \mu)^2}{2\sigma^2}
    \]
    
    代码里通常会计算每个像素的 \verb|log_prob|，然后求和或求平均。
    \item 累加：把这一步算出的 \verb|log_prob| 加到总累加器上。
  \end{itemize}
  \item 返回结果：循环结束后，\verb|log_prob| 累加器里就是这一批每张图片的总对数概率。
\end{enumerate}

这个值 \(log \Pi\) 在强化学习微调里是必需的：它代表策略（扩散模型）在给定 prompt 下生成图片 \(x_0\) 的概率，PPO 这类策略梯度算法要用它。
