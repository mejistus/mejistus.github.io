\section{Why i3wm}

i3 is a tiling window manager for X11. Windows do not overlap. Each one takes a region of the screen, and the layout reflows when windows open or close.

My desktop used to be a pile of overlapping terminals and browser tabs. Tiling removed the need to arrange them by hand.

\section{The Setup}

The config runs on i3-wm. It is not the flashiest setup, but i3 is small, stable, and stays out of the way, which is what I want from a window manager.

Most of the configuration comes from existing open-source projects, with small changes of my own. I did not set out to write anything new; the aim was a setup that works every day.

\section{Key Bindings That Matter}

Two years in, these are the bindings I actually use:

\begin{center}
\begin{tabular}{ll}
\toprule
Key & Action \\
\midrule
\verb|Mod+Enter| & Open terminal \\
\verb|Mod+d| & Launch app menu (dmenu) \\
\verb|Mod+[1-9]| & Switch workspace \\
\verb|Mod+Shift+[1-9]| & Move window to workspace \\
\verb|Mod+h/j/k/l| & Navigate windows (vim-style) \\
\verb|Mod+Shift+q| & Close window \\
\verb|Mod+r| & Reload config \\
\verb|Mod+Shift+c| & Restart i3 \\
\bottomrule
\end{tabular}
\end{center}

Vim-style navigation took the longest to learn. Now I reach for it without thinking.

\section{Polybar Customization}

The status bar supports multiple configurations. For example, to activate style \#2 with CPU monitoring:

\begin{lstlisting}[language=bash]
python ~/.config/polybar/scripts/change.py --select 2
\end{lstlisting}

Or edit the configuration files directly to create your own combination.

\section{Neovim Integration}

I use a customized NvChad configuration so the editor matches the rest of the setup. The theme is OneDark (though I personally use Dracula).

Key mappings are defined in \verb|mappings.lua|. With qutebrowser handling the web, most tasks can be done from the keyboard.

\begin{quote}
Note: The code hover key has been remapped to \verb|F|. Double-tap \verb|Shift+f| to activate.
\end{quote}

\section{A Note on Colours}

The accent colour is \verb|#c47c5a|, a muted rust orange. It is the same colour I use on my personal site, and it sits well against the cool greys in the editor and terminal.

One accent colour is enough. Changing every colour at once makes the screen harder to read.
