From Standard Residual Connection to Hyper-Connections, mHC and Attention-Residual.

\subsection{起点：标准残差为什么强}

标准残差层写成\(x_{l+1}=x_l+F_l(x_l)\).

跨很多层展开，有\(x_L = x_l + \sum_{i=l}^{L-1}F_i(x_i)\).

于是对 \(x_l\) 求导：

\[
\frac{\partial x_L}{\partial x_l}
=
I+
\frac{\partial}{\partial x_l}
\sum_{i=l}^{L-1}F_i(x_i).
\]

再乘上 loss 的梯度：

\[
\boxed{
\frac{\partial \mathcal L}{\partial x_l}
=
\frac{\partial \mathcal L}{\partial x_L}
\left(
I+
\frac{\partial}{\partial x_l}
\sum_{i=l}^{L-1}F_i(x_i)
\right)
}
\]

残差里始终有一条 identity path。即使 \(F_l\) 学得不好，梯度仍然有一条“保底直通路”能穿过去，所以深层网络更稳。

\hrule

\subsection{为什么还要改：单残差流太“窄”}

标准残差稳定，但也很“死板”。每层只能拿到上一层汇总后的单状态，更早层的信息都已经被压进一个 residual stream 里。深度增加后，容易出现一种张力：一边想保住梯度传播，另一边又会遇到表示过度混合、层间信息难以选择性保留的问题。

所以后续改进开始动连接本身，而不只是把 \(F\) 做得更强。

\hrule

\subsection{Hyper-Connections：把单流变成多流}

HC 的想法是：既然单一 residual stream 太窄，那就把它扩成 \(m\) 个并行流，并且让层与层之间学会“怎么混”。

其单层形式可写成

\[
x_{l+1}
=
H^{\mathrm{res}}_l x_l
+
(H^{\mathrm{post}}_l)^\top
F\!\left(H^{\mathrm{pre}}_l x_l\right).
\]

这里：

\begin{itemize}
  \item \(x_l\) 不再是单流，而是一个多流状态；
  \item \(H_l^{\mathrm{pre}}\)：从多流里读出本层要处理的输入；
  \item \(H_l^{\mathrm{post}}\)：把本层输出写回多流；
  \item \(H_l^{\mathrm{res}}\)：直接在 residual streams 之间做线性混合。
\end{itemize}

收益是连接拓扑更丰富，不再只有“上一层 + 当前层输出”这一种连法。不同深度的信息也可以以不同强度进入不同流，层间可重排。状态从一条通道扩成了多条通道，表达容量更大。

代价出在 identity 上。

\hrule

\subsection{HC 的问题：identity 不再天然成立}

对 HC 跨层展开后，残差主干不再是简单的 \(x_l\)，而会变成一串混合矩阵的连乘：

\[
x_L
=
\left(\prod H^{\mathrm{res}}\right)x_l
+
\text{(residual terms)}.
\]

这时再看梯度，原来标准残差里的那个“干净的 \(I\)”不见了，取而代之的是

\[
\frac{\partial \mathcal L}{\partial x_l}
\sim
\frac{\partial \mathcal L}{\partial x_L}
\left(\prod H^{\mathrm{res}}\right)
+\cdots
\]

问题在这里：如果这些 \(H^{\mathrm{res}}\) 无约束地学，多层连乘后就可能偏离 identity 很远，forward 的信号守恒和 backward 的稳定传播都会被破坏。

HC 用更强的连接表达力换来了 identity 路径被污染的风险。

\hrule

\subsection{mHC：把 HC 拉回“安全流形”}

mHC 没有否定 HC。它给 \(H^{\mathrm{res}}\) 加上几何约束，让多流混合仍然保留类似 identity 的稳定性。

具体做法是让 \(H^{\mathrm{res}}\) 不再是任意矩阵，而是投影到一个受约束的集合上，例如双随机矩阵所在的 Birkhoff polytope。

行和为 1、列和为 1 的混合矩阵更像“守恒型混合”：它允许流之间重新分配信息，但不至于在层层传播中把整体量级越放越大，或越缩越小。

于是 HC 的式子还在：

\[
x_{l+1}
=
H^{\mathrm{res}}_l x_l
+
(H^{\mathrm{post}}_l)^\top
F\!\left(H^{\mathrm{pre}}_l x_l\right),
\]

但现在 \(H^{\mathrm{res}}_l\) 被限制在一个“不会把 identity 完全玩坏”的空间里。

mHC 相比 HC 的变化在于：HC 解决的是“连接太窄”，mHC 解决的是“连接太自由”。

\hrule

\subsection{Attention-Residual：继续往前走，但思路变了}

HC 和 mHC 都属于多状态递推：维护一个“当前时刻的多流状态”，下一层主要还是从这个“上一时刻的状态”里读、写、混。

Attention-Residual 这条线换了一种做法：直接、选择性地访问更早各层的输出，不再只依赖“上一层压缩好的状态”。它把“沿深度传播”的机制改成了对历史层输出做 attention 聚合。

当前层的输入是一次聚合，不再局限于 \(x_{l-1}\) 或多流状态：

\[
x_{l+1}
=
\mathrm{AttnDepth}\!\big(x_0,x_1,\dots,x_l\big)
+
F_l(\cdot).
\]

关键变化在于从状态混合变成历史检索，从线性递推变成按内容选择过去哪些层最重要。

从这个视角看，HC 和 mHC 更像 depth-wise linear attention，只不过状态是矩阵或多流形式；Attention-Residual 更像 depth-wise softmax attention，直接对更早层做选择性读取。

它不再只依赖立即前驱状态，更早层的贡献可以被显式检索，而不是先被压缩掉。PreNorm 那种深度累计导致的幅值线性增长、PostNorm 那种反复缩放导致的梯度衰减，也都避开了。

\hrule

\subsection{这几代方法改了什么}

如果把这几代方法放在一起看，是在不断放宽“层与层如何通信”的方式。

\subsubsection{(a) 标准 Residual}

只允许：

\[
x_{l+1}=x_l+F_l(x_l)
\]

这是最稳、最干净的版本，连接表达力也最低。

\subsubsection{(b) HC}

允许单流 \(\to\) 多流，当前层与 residual stream 之间可以学习读写，流与流之间也可以学习混合。表达力增强很多，但 identity 不再天然成立。

\subsubsection{(c) mHC}

在 HC 基础上约束混合矩阵，使多流通信保持“守恒型”和“稳定型”。它想兼得 HC 的表达力与 residual 的稳定性。

\subsubsection{(d) Attention-Residual}

不再把“跨层通信”局限为多流递推，而是直接对过去各层输出做注意力检索。

层深本身成了一个可注意的维度，历史层的贡献可以选择访问，而不是被动压缩保存。

\hrule

\subsection{和你那条求导公式怎么连起来}

你那条标准残差公式：

\[
\frac{\partial \mathcal L}{\partial x_l}
=
\frac{\partial \mathcal L}{\partial x_L}
\left(
I+
\frac{\partial}{\partial x_l}
\sum_{i=l}^{L-1}F_i(x_i)
\right)
\]

核心在那个 \(I\)。

后面所有方法都在回答两个问题：能不能让跨层通信更强，还能不能保住那个“像 \(I\) 一样安全”的通路。

这条链大致是：Residual 先把 \(I\) 立住；HC 发现光有 \(I\) 不够、通信太弱，于是扩成多流；mHC 发现多流太自由会把 \(I\) 弄丢，于是加几何约束；Attention-Residual 进一步把“安全通路”写成对历史层的选择性聚合，而不必是局部加法。

几代方法都在处理同一个问题：更强的跨层信息流动下，怎么保住深层网络的训练稳定性。
