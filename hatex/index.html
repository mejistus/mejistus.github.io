hatex

LaTeX articles and slides, rendered in the browser.

One script turns a .tex file into a web page: numbered equations, booktabs tables, figures, TikZ, theorems and proofs, algorithms, citations and clickable cross-references, two-column layouts and beamer slides. No TeX installation and no build step.

What is hatex?

html + latex = hatex

Papers, theses and talks are written in LaTeX; the web is written in HTML. hatex joins the two: you keep writing LaTeX, and your readers get a web page, with links, search, copy and paste, any screen size and no PDF viewer.

The work happens in the reader's browser. hatex parses the .tex source into HTML, typesets the maths with KaTeX and compiles TikZ with real TeX running in WebAssembly, so there is nothing to install and nothing to build. If you'd rather ship plain HTML, the same parser runs in Node at build time.

It covers the part of LaTeX that articles and talks actually use: sections, numbered equations, booktabs tables, figures, TikZ, theorems, algorithms, citations and cross-references, two-column layouts and beamer slides. Anything it doesn't know degrades to its text instead of breaking the page.

Quick start

Load KaTeX (for the maths) and hatex, then render a source into an element:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css">
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js"></script>
<link rel="stylesheet" href="https://mejistus.github.io/hatex/lib/hatex.css">
<script src="https://mejistus.github.io/hatex/lib/hatex.js"></script>

<article id="paper"></article>
<script>
  fetch('paper.tex')
    .then(r => r.text())
    .then(tex => HaTeX.render('#paper', tex));
</script>

The source can be a whole document (\documentclass … \begin{document}) or just its body. The preamble is read for \newcommand, \definecolor, \newtheorem and \usetikzlibrary. Serve the page over HTTP, not file://, so the .tex file and TikZ SVGs can be fetched. For highlighted code, add Prism and its language components; don't add a Prism theme.

What it renders

AreaSupported
Structure\section … \subsubsection (numbered, * for unnumbered), \paragraph, abstract, nested itemize / enumerate / description, quote, center, \footnote
Maths (KaTeX)$…$, \(…\), \[…\]; equation, align, gather, multline, … numbered per row, \nonumber, \label / \eqref; \newcommand and \DeclareMathOperator
Tablestabular with \toprule / \midrule / \bottomrule, \hline, |, \multicolumn, \multirow, \cmidrule(lr), \rowcolor / \cellcolor; \resizebox{\linewidth}{!}{…} shrinks a wide table to fit
Figures\includegraphics[width=…\linewidth], subfigure (a), (b), side-by-side minipage, \caption; click an image to zoom
TikZtikzpicture, tikzcd, pgfplots axis; libraries detected from the code; nn* styles for network diagrams
Theoremstheorem, lemma, proposition, definition, … and proof; your own with \newtheorem
Algorithmsalgorithm + algorithmic: \State, \If, \For, \While, \Repeat, \Function, \Comment, …
Codelstlisting, minted, verbatim, \verb; highlighted when Prism is loaded
References\ref, \eqref, \autoref, \cref, \cite{a,b}, thebibliography; each link scrolls to its target
Text\textbf, \emph, \texttt, \sout, \hl, \textcolor, \href, \url, sizes, accents, dashes and quotes
Chinesecaptions and names switch to 图 / 表 / 定理 / 证明 / 参考文献; no stray spaces at CJK line breaks; \begin{guji} sets a vertical manuscript-scroll page (right to left, ruled columns, 句讀 marks in place of punctuation) and \jiazhu{…} adds two-line interlinear notes (夾注)
Layout\documentclass[twocolumn] and multicols: balanced columns on a wide screen, one column on a phone; headings, the abstract and figure* / table* span both columns, and equations too wide for a column are scaled to fit
Slides\documentclass{beamer}: frame, \titlepage, \tableofcontents, block / alertblock / exampleblock, columns; any aspect ratio (16:9, 4:3, 1:1, …); a full-screen Present mode; overlays (\pause, <2->) show every step at once
